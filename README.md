# Vipsies Demo

Snelle proof-of-concept van een zelfstandige Vipsies-webshop buiten Shopify.

## Wat zit erin?
- Responsive eigen storefront
- Productgrid en merksecties
- Werkende demo-winkelwagen
- Nieuwsbrief-interactie
- Geen backend of echte checkout: dit is bewust een visuele/technische demo

Open `index.html` lokaal of publiceer de repository met GitHub Pages.
